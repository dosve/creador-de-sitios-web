# 🚀 Guía Rápida: Duplicar Sitio Web

## En 3 pasos

### Paso 1️⃣: Abre tu sitio
Ve al dashboard y selecciona el sitio que quieres duplicar.

### Paso 2️⃣: Haz clic en "Duplicar"
En la esquina superior derecha verás el botón **Duplicar** (al lado de Editar).

```
┌─────────────────────────────────┐
│ Mi Sitio Web                    │
│ Descripción del sitio           │ [Publicado] [Duplicar] [Editar]
└─────────────────────────────────┘
```

### Paso 3️⃣: Completa el formulario
- **Nombre**: Escribe el nombre del nuevo sitio (ej: "Mi Sitio Copia")
- **Slug**: (Opcional) Se genera automáticamente si lo dejas en blanco
- Haz clic en **Duplicar Sitio Web**

¡Listo! Tu sitio está duplicado ✨

---

## ¿Qué se copia?

| Elemento | ¿Se copia? |
|----------|-----------|
| Páginas | ✅ Sí |
| Contenido HTML | ✅ Sí |
| Menús | ✅ Sí |
| Categorías | ✅ Sí |
| Etiquetas | ✅ Sí |
| Blog Posts | ✅ Sí |
| Componentes | ✅ Sí |
| Configuración | ✅ Sí |
| Dominios | ❌ No (configura nuevos si quieres) |
| Archivos | ⚠️ Referencias (no físicamente) |

---

## Notas importantes

📌 **El nuevo sitio inicia como BORRADOR**
- Debes revisarlo y publicarlo cuando esté listo
- Puedes editar todo sin afectar el original

📌 **Slug automático**
- Si escribes "Mi Sitio Web" como nombre
- El slug será "mi-sitio-web" (puedes cambiarlo)
- Debe ser único, no puede haber dos sitios con el mismo slug

📌 **Copias independientes**
- El nuevo sitio es totalmente independiente
- Cambios en uno NO afectan al otro
- Puedes duplicar un sitio duplicado (sin límite)

## Preguntas frecuentes

**¿Se pierden datos al duplicar?**
No, el original no se modifica en absoluto.

**¿Puedo cambiar el nombre después?**
Sí, entra a Editar en la configuración del sitio.

**¿Cuánto tarda?**
Solo algunos segundos.

**¿Hay límite de duplicaciones?**
No, puedes duplicar tantos sitios como quieras.

**¿Se copian los visitantes/estadísticas?**
No, el nuevo sitio comienza con estadísticas en 0.

## Troubleshooting

### Error: "Slug ya está en uso"
**Solución**: Escribe otro slug o déjalo en blanco para que se genere automáticamente.

### Error: "Nombre requerido"
**Solución**: Asegúrate de escribir un nombre para el nuevo sitio.

### El sitio se duplica pero no aparece
**Solución**: Recarga la página (F5) o vuelve al dashboard.
